BLACKTHORN ATS

Applicant tracking

The recruiter console is a desktop client. This build ships the API only.

API

POST /api/session                 {"email": "...", "password": "..."}
POST /api/logout
GET  /api/me

POST /api/password-reset/request  {"email": "..."}
POST /api/password-reset/verify   {"email": "...", "token": "...", "newPassword": "..."}

POST /api/candidates/search       {"filter": { ... }}
GET  /api/candidates/:id

Saved searches

The console builds filters client-side so recruiters can combine conditions the API never had to anticipate. A filter is a plain object:

{"filter": {"stage": "onsite"}}
{"filter": {"location": "Rotterdam", "stage": {"$ne": "rejected"}}}
{"filter": {"compensation.expected": {"$lte": 90000}}}

Responses carry id, name, headline, location, stage and skills. Compensation and scorecards are filterable but never returned.
