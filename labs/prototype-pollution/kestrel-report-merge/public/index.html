KESTREL REPORTS

Workspace API

Kestrel has no web UI yet — the desktop client talks to this API directly. Every route takes a session cookie.

POST   /api/session            {"email": "...", "password": "..."}
POST   /api/logout

GET    /api/preferences        your preference document
PATCH  /api/preferences        deep-merges the JSON body into it

GET    /api/reports            reports in your workspace
GET    /api/exports            full-fidelity export      (needs exports:read)
POST   /api/reports/:id/render hands a report to the engine (needs reports:render)

Roles

analyst can read reports. finance can also render and export. admin can do both plus manage the workspace. Your account is an analyst.
