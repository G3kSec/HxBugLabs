LANTERN

Campaign editor

Lantern's editor is a desktop app; this build only ships the API.

Merge tags

Campaign bodies are templates. Anything in double braces is replaced when the mail is built:

{{ recipient.firstName }}   {{ recipient.lastName }}
{{ recipient.company }}     {{ recipient.email }}
{{ campaign.subject }}      {{ workspace.name }}

Preview renders your draft against a sample recipient before you schedule a send.

API

POST /api/session                    {"email": "...", "password": "..."}
GET  /api/campaigns
PUT  /api/campaigns/:id              {"body": "...", "subject": "..."}
POST /api/campaigns/:id/preview      {"body": "..."} renders a draft without saving
